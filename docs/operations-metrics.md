# 运行监控指标说明

当前监控指标面向本地单用户模拟交易系统，用于快速判断行情、策略和模拟交易链路是否健康，不替代生产级 Prometheus/Grafana 或告警平台。

## 接口

`GET /api/v1/monitoring/operations/metrics`

返回结构：

- `market_data`：行情数据新鲜度、最新交易日、滞后天数、日线行数、标的数、数据源数。
- `strategy_execution`：策略运行总数、成功数、失败数、成功率、最近运行时间。
- `trading`：委托总数、成交/拒绝/撤销/待撮合数量、成交成功率、成交记录数、最近委托/成交时间。

## 核心口径

- 行情新鲜度：本地日线最新 `trade_date` 与参考日期的差值，超过 5 天标记为 `stale`。
- 策略成功率：`success` 策略运行数 / 全部策略运行数。
- 交易成功率：`filled` 委托数 / 全部委托数。
- 当前接口读取数据库聚合结果，不主动访问外部行情源。

## 边界

- 当前是 JSON 查询接口，未接入 Prometheus exposition format。
- 当前不做长期指标归档、告警阈值管理或可视化面板持久化。
- 若未来需要生产监控，应先明确指标名、标签维度、采样周期、保留周期和告警责任人。
