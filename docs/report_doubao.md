# 模拟炒股系统策略能力升级开发计划
针对你现有的Vue+Python前后端分离模拟炒股项目，我们将通过集成成熟开源量化工具，用8周时间完成从"简单日线判断"到"专业量化闭环"的升级，核心解决**数据不准、回测不可靠、模拟胜率偏低**的问题，为后续实盘落地打下可靠基础。

---

## 项目基础信息
| 项 | 说明 |
|----|------|
| 项目目标 | 构建「数据-回测-优化-模拟」的量化研发闭环，将模拟盘策略胜率提升10%-15%，验证策略的真实有效性 |
| 项目周期 | 8周 |
| 兼容现状 | 完全复用你现有的模拟下单、用户账户、持仓管理功能，前端仅新增功能页面，无重构成本 |
| 用到的开源工具 | AkShare、VectorBT、Qlib、QUANTAXIS、PyFolio（均为Python生态成熟开源项目，可无缝集成） |

---

## 分阶段开发计划
### 阶段1：数据层重构与标准化（第1周）
**核心目标**：解决最基础的「数据陷阱」问题，用精准、标准化的行情数据，消除复权错误、数据缺失导致的策略误判，为所有后续环节打下基础。

#### 具体任务
1. **数据源替换**
   - 将你后端原有的行情数据源，替换为**AkShare**，获取精准的前复权A股日线数据（覆盖2010年至今全市场4000+股票）
   - 同步补充你之前关注的**主力资金净流入、涨跌停标记、停牌标记**等辅助数据，为后续策略过滤做准备
2. **本地数据缓存体系**
   - 搭建本地行情数据表，缓存全量历史数据，避免重复请求接口，突破AkShare的频率限制，同时将数据查询速度提升10倍以上
   - 开发**每日增量更新脚本**：每日下午4点收盘后，自动拉取当日最新行情、资金流数据，增量更新到本地库，保证数据时效性
3. **数据清洗与校验**
   - 校验复权数据准确性：对比通达信官方数据，确保价格误差在0.01元以内
   - 清洗异常数据：标记ST股、退市股、停牌股、涨跌停股，过滤无效标的，避免策略误买入
   - 补全时间序列：补全节假日、停牌日的空数据，保证行情时间序列的连续性
4. **无感知兼容**
   - 保持你原有后端的行情接口完全不变，前端无需任何修改，实现对现有系统的平滑升级

#### 交付物
- 标准化A股行情数据库（2010年至今全量数据）
- 每日自动增量更新的定时任务
- 数据质量校验报告
- 兼容原有接口的新数据服务模块

### 阶段2：回测引擎集成与现有策略验证（第2-3周）
**核心目标**：用专业回测引擎，验证你现有日线策略的**真实历史表现**，排查你之前手写回测的隐藏问题（比如未来函数、逻辑bug），搞清楚当前策略到底能不能打。

#### 具体任务
1. **轻量回测引擎集成**
   - 选择**VectorBT**（轻量、高性能、易集成的Python回测库）作为回测引擎，集成到你的Python后端，完全替代你原有的手写回测逻辑
   - VectorBT原生支持pandas，和你现有的数据处理逻辑完全兼容，无需重构
2. **现有策略1:1迁移**
   - 将你当前的买入/卖出判断逻辑（比如MA金叉、自定义日线条件），完整迁移到VectorBT的信号体系中，保证逻辑100%对齐
3. **全市场环境回测**
   - 用2010-2025年的全量历史数据运行策略，覆盖：
     - 牛市：2015年、2019年、2020年
     - 熊市：2018年、2022年
     - 震荡市：2023年、2024年
   - 确保策略在所有市场环境下的表现都可验证，而不是只在最近几个月的行情里有效
4. **隐藏问题排查**
   - **未来函数检测**：排查你的策略是否无意中用了未来数据（比如用当日收盘数据生成当日买入信号，实际应该次日才能交易），这是新手策略最常见的致命bug
   - **逻辑对齐校验**：对比原手写回测的结果，找出差异点，比如是否忽略了手续费、滑点、涨跌停限制
   - 生成基础绩效报告：计算现有策略的真实胜率、年化收益、最大回撤，让你知道当前策略的真实水平
5. **前端可视化扩展**
   - 在Vue前端新增「回测结果」页面，展示策略的净值曲线、持仓变化、交易记录，直观看到策略的历史表现

#### 交付物
- 集成完成的回测引擎模块
- 现有策略的全历史回测报告，包含问题排查结果
- 前端回测结果展示页面
- 现有策略的真实绩效指标（胜率、年化、回撤等）

### 阶段3：策略优化与因子增强（第4-5周）
**核心目标**：针对你的日线策略，通过因子增强、参数寻优，提升策略的胜率，同时严格防控过拟合风险。

#### 具体任务
1. **有效因子库集成**
   - 引入**Qlib的Alpha158标准因子库**：这是微软亚洲研究院针对A股市场验证过的158个有效因子，自动帮你计算技术因子（RSI、MACD、布林带）、资金因子（主力资金占比、大单净流入）、量价因子（换手率、量能变化），不用你自己手写指标
   - 引入**QUANTAXIS的股票分类数据**：实现板块/概念/市值的选股过滤，比如只在沪深300、高股息、破净等优质板块选股，排除垃圾股，提升策略的基础胜率
2. **买入条件优化**
   - 将你原有的单一均线条件，扩展为「基础信号+因子过滤」的复合条件，比如：
     > 原条件：MA5上穿MA20 → 新条件：MA5上穿MA20 **且** 主力资金净流入 **且** 换手率处于5%-20%合理区间 **且** 标的不是ST股
   - 加入涨跌停成交限制：回测中自动过滤「涨停买入、跌停卖出」这种实盘不可能完成的交易，让回测更真实
3. **参数寻优与泛化验证**
   - 用VectorBT的参数扫描功能，对你的策略参数（比如均线周期、因子阈值）进行全局寻优，找到**样本内（2010-2020年）**表现最优的参数组合
   - 严格用**样本外数据（2021-2025年）**验证最优参数的有效性，确保参数不是过拟合到历史数据，而是具备泛化能力（这是防止过拟合的核心手段）
4. **全市场选股扩展**
   - 如果你的策略之前是单股票的，扩展为全市场选股策略：每天从全市场股票中选出符合条件的标的，构建投资组合，分散风险，提升策略的稳定性

#### 交付物
- 优化后的复合策略逻辑
- 参数寻优与样本外测试报告，确认策略的泛化能力
- 全市场选股的策略回测报告，预期胜率提升10%-15%
- 前端策略参数配置页面，支持你在线调整策略参数

### 阶段4：风险评估与绩效分析（第6周）
**核心目标**：从单纯的「胜率」评估，升级为专业的量化绩效评估，全面衡量策略的风险收益能力，确保策略不是"赚小钱亏大钱"。

#### 具体任务
1. **专业绩效分析模块集成**
   - 集成**PyFolio**（量化行业标准的绩效分析库），实现专业的策略评估能力
2. **核心风险指标计算**
   - 风险收益比指标：夏普比率、索提诺比率、卡玛比率，衡量策略每承担1单位风险能赚多少钱
   - 下行风险指标：最大回撤、波动率、VaR风险价值，衡量策略最多会亏多少
   - 交易效率指标：月度/年度收益分析、换手率分析，评估策略的交易频率是否合理
3. **极端市场压力测试**
   - 将策略放到极端市场环境下测试：2015年股灾、2018年全年熊市、2022年疫情大跌，验证策略的抗风险能力
   - 测试不同仓位下的策略表现，找到最优的仓位配置，平衡收益和风险
4. **前端分析页面扩展**
   - 在前端新增「绩效分析」页面，展示所有风险指标、压力测试结果，让你全面了解策略的风险情况，而不是只看赚了多少钱

#### 交付物
- 集成完成的绩效分析模块
- 策略的完整绩效分析报告
- 极端市场压力测试报告
- 前端绩效分析展示页面

### 阶段5：模拟盘闭环与迭代（第7-8周）
**核心目标**：将优化后的策略，无缝集成到你现有的模拟盘系统，实现自动化的模拟交易，构建完整的「数据-策略-交易」闭环。

#### 具体任务
1. **策略信号集成**
   - 将优化后的策略逻辑，集成到你现有的模拟盘系统中，替换原有的买入/卖出判断逻辑
2. **模拟盘真实化改造**
   - 加入真实交易成本：万2.5佣金、千1印花税、过户费，和实盘完全一致
   - 加入滑点模拟：默认0.1%的滑点，模拟实盘的成交冲击成本，避免模拟盘收益虚高
   - 加入实盘成交限制：涨停无法买入、跌停无法卖出、停牌无法交易，完全对齐实盘规则
3. **自动化交易流程**
   - 配置每日定时任务：每日下午4点收盘后，自动完成「数据更新→策略信号计算→模拟下单」全流程，无需人工干预
   - 直接对接你现有的模拟下单接口，策略生成的信号直接复用你已经做好的账户、持仓、订单管理功能，不用改原有下单逻辑
4. **监控与告警**
   - 开发系统监控模块，监控数据更新、策略运行、模拟下单的状态
   - 异常告警：如果数据更新失败、策略信号异常（比如单日买入超过10只股票）、模拟下单失败，自动发送邮件/企业微信告警
5. **灰度验证**
   - 先运行1周的灰度模拟，对比模拟盘的实时表现和回测结果，确认没有偏差后正式上线

#### 交付物
- 集成完成的优化版模拟盘系统
- 自动化每日交易的定时任务
- 系统监控与告警模块
- 灰度验证报告，确认模拟盘运行正常

## 风险防控措施
| 风险类型 | 防控手段 |
|----------|----------|
| 过拟合 | 1. 严格划分训练/测试集，参数寻优只用训练集；2. 限制参数搜索范围，避免极端参数；3. 优先简单逻辑，不加入过多条件 |
| 未来函数 | 1. 回测引擎严格遵循时间序，禁止使用未来数据；2. 上线前用VectorBT的未来函数检测工具做全量检查 |
| 数据风险 | 1. 数据更新失败自动重试+告警；2. 每月定期校验数据准确性，和官方数据做对比 |
| 策略风险 | 1. 限制单只股票仓位不超过10%，分散风险；2. 限制单日交易次数，避免过度交易 |

## 后续规划（8周之后）
1. **模拟盘验证期**：让优化后的策略运行3-6个月的模拟盘，验证其在真实市场中的表现，确认模拟盘收益和回测结果无偏差
2. **实盘准备**：当模拟盘稳定盈利3个月以上，开始集成实盘能力，比如对接vnpy/tqsdk的券商API，实现实盘自动下单
3. **策略迭代**：持续迭代策略，加入基本面因子、舆情因子，进一步提升胜率
4. **多周期扩展**：从日线策略扩展到小时线/分钟线策略，覆盖更多交易场景
