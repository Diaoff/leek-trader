### 重点展开：仅 3 个有实际讨论价值

#### ⚠️ AData（最有集成价值，但需评估）

**当前 leek-trader 行情层**：新浪 / 东方财富 / 腾讯 / BaoStock，缺口在**资金流向、基本面、概念板块**。

AData 恰好补的是这三块：

| AData 数据字段 | leek-trader 当前是否有 | 补缺价值 |
|---|---|---|
| 个股资金流向 | ❌ 无 | 🔴 高（智能选股评分直接受益） |
| 主力净流入趋势 | ❌ 无 | 🔴 高 |
| 概念板块涨跌 | △ 东财部分覆盖 | 🟡 中 |
| 基本面（PE/PB/ROE） | ❌ 无 | 🔴 高（因子研究基础） |
| 历史行情 | ✅ BaoStock 已有 | 低（重复） |

**但 plan.md 明确要求**：AData 集成需先走 `Phase 10.1`（评估许可证、维护状态、失败模式、缓存策略），不能直接上主链路。

**建议**：可用 AData 做一个只读 spike（`backend/app/market/providers/adata_spike.py`），只评估，不接入，作为 10.1 的输出。

---

#### ⚠️ efinance（可作第三数据源备选）

比 AData 接口更简单，适合快速 spike，但覆盖的字段与现有数据源重叠度更高。

主要增量价值：**基金净值数据**（leek-trader 暂无）和 **债券行情**。对当前 A 股量化研究路线价值有限，优先级低于 AData。

---

#### ⚠️ Ashare（价值最低但成本最小）

本质是对新浪 / 腾讯行情接口的轻量封装，leek-trader 已经自己对接了新浪，引入 Ashare 实际是用别人封装替换自己封装。

**唯一有用的场景**：现有新浪 provider 挂了且来不及修，Ashare 可以作为临时兜底。但 leek-trader 已有多源降级，这个场景本就已覆盖。
