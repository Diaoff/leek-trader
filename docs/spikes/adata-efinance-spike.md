# AData / efinance 只读 Spike 评估

## 结论

- 当前不将 `adata` 或 `efinance` 加入生产依赖。
- 当前不把二者接入 provider registry、主 API、普通页面或数据库入库链路。
- 保留可选 spike 脚本 `backend/scripts/spike_data_providers.py`，仅用于本地环境检测依赖是否存在和记录候选字段。

## 字段覆盖

| 包 | 候选字段/能力 | 与当前系统关系 | 初步结论 |
| --- | --- | --- | --- |
| AData | A 股列表、基本面、概念板块、资金流向 | 可补充 BaoStock/东方财富之外的研究字段 | 先观察，不进入生产依赖 |
| efinance | 东方财富封装行情、基金净值、指数、行业数据 | 与现有 EastMoney/Sina/Tencent 有重叠，也可作为基金/行业候选 | 先观察，不进入生产依赖 |

## 失败模式

| 失败模式 | 影响 | 缓解 |
| --- | --- | --- |
| 网络失败 | spike 或未来 provider 返回失败 | 不影响主链路；仅可选运行 |
| 字段变更 | 解析结果不稳定 | 正式接入前必须固定样本测试 |
| 限频 | 大批量研究不稳定 | 必须有缓存和速率限制后再接入 |
| 返回空集 | 排名/研究结论缺失 | 必须输出 missing reason |
| 编码异常 | 中文字段解析失败 | 正式接入前加编码样本测试 |

## 依赖与许可证

- `efinance`：公开项目资料显示为 MIT；正式接入前需在 PR 中再次核验许可证文本。
- `adata`：公开仓库含 `LICENSE`；正式接入前需核验具体许可证文本和再分发约束。
- 两者当前都不加入 `backend/requirements.txt`。

## Go / No-Go

- 当前决策：No-Go for production dependency。
- 可进入下一步的条件：明确许可证、维护状态可接受、字段覆盖补齐明确缺口、失败不影响主链路、有缓存/限频/测试/回滚方案。
