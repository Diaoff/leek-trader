# 股票模拟交易系统功能重构计划

## 1. 项目分析

### 1.1 stock-simulator 功能分析
- **菜单结构**：仪表盘、行情与选股、策略管理、交易与持仓、盈亏分析
- **核心功能**：
  - 仪表盘：资产概览、持仓图表、收益趋势、自选股预览、活跃策略
  - 行情与选股：股票搜索、市场筛选、股票详情
  - 策略管理：策略列表、信号管理、策略绩效
  - 交易与持仓：买卖订单、持仓管理、订单历史
  - 盈亏分析：收益分析、历史绩效
- **UI 特性**：粒子背景、市场状态显示、响应式布局

### 1.2 frontend 现状分析
- **菜单结构**：仪表盘、行情、策略、交易与持仓（缺少盈亏分析）
- **已实现功能**：基础组件、API 客户端、状态管理、基础视图
- **缺失功能**：
  - 股票搜索功能
  - 粒子背景效果
  - 市场状态显示
  - 更丰富的仪表盘功能
  - 活跃策略展示
  - 自选股实时行情
  - 盈亏分析模块

## 2. 重构计划

#### 2.2.3 策略管理功能增强
- 策略列表展示
- 信号管理
- 策略绩效分析
- 策略启用/禁用功能

#### 2.2.4 交易与持仓功能增强

- 持仓管理表格

#### 2.2.5 盈亏分析功能实现
- 收益分析图表
- 历史绩效统计

### 2.3 UI 优化
- 实现粒子背景效果

## 4. 风险与应对

### 4.1 风险
- 后端 API 接口不完全匹配
- 数据可视化性能问题
- 响应式布局适配困难
- 功能实现复杂度超出预期

### 4.2 应对策略
- 优先实现核心功能，确保主链路畅通
- 使用模拟数据进行前端开发
- 分阶段实现，逐步完善功能
- 定期测试，及时发现并解决问题

## 5. 预期成果

- 与 stock-simulator 功能一致的完整前端应用
- 现代化的 UI 设计和用户体验
- 完善的功能模块和数据流
- 良好的代码结构和可维护性
